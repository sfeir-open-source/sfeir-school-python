# Installation de l’environnement

**uv : l'outil tout-en-un**

* Outil d'Astral, écrit en Rust : **ultra-rapide**.
* Python, environnement virtuel, dépendances, verrouillage : tout dans une seule commande.

```bash
uv python install 3.14   # installe Python 3.14
uv init mon-projet       # crée le projet (pyproject.toml, .python-version)
uv add fastapi           # ajoute une dépendance (pyproject.toml et uv.lock)
uv run main.py           # exécute le code dans l'environnement du projet
uv sync                  # installe exactement ce que décrit uv.lock
```

<!-- .element: class="big-code" -->

Notes:
Ces cinq commandes suffisent pour démarrer. `uv python install` installe un interpréteur dans un dossier géré par uv : pas besoin de l'installer à la main. `uv init` crée un projet, `uv add` ajoute une dépendance et met à jour le verrou, `uv run` exécute une commande dans l'environnement du projet, en créant le venv si besoin, et `uv sync` réaligne l'environnement sur le verrou, par exemple après un `git pull`.

Vous n'avez jamais besoin d'activer le venv avec uv : `uv run` s'en charge.

uv remplace à lui seul `pip`, `venv`, `pip-tools` et une partie de Poetry. Poetry 2.x est toujours maintenu, mais uv est devenu le choix par défaut.

# Installation de l’environnement

**Les fichiers d'un projet uv**

* `pyproject.toml` : métadonnées, dépendances, configuration des outils.
* `uv.lock` : versions exactes de toutes les dépendances, générées par uv. À commiter avec `pyproject.toml`.

```toml
[project]
name = "mon-projet"
requires-python = ">=3.14"
dependencies = [
    "fastapi[standard]>=0.160",
]

[dependency-groups]
dev = ["pytest>=9"]
```

<!-- .element: class="medium-code" -->

Notes:
Le `pyproject.toml` décrit ce que vous voulez ; le `uv.lock` décrit ce qui est réellement installé : toutes les dépendances, y compris les indirectes, avec des versions exactes. Les deux vont dans Git. Si le verrou est à jour, `uv sync` produit le même environnement sur toutes les machines.

`requires-python` impose la version minimale de Python. `[dependency-groups]` (PEP 735) regroupe les dépendances de développement, qui ne sont pas publiées avec le projet : `uv add --dev pytest`.

Pour aller plus loin : `pylock.toml` (PEP 751) est un format de verrou standard, lisible par d'autres outils que uv, produit avec `uv export --format pylock.toml`.
