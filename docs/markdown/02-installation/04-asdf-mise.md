# Installation de l’environnement

**ASDF / MISE**

*   Gestionnaires de versions pour de nombreux outils (Python, Node.js, etc.).
*   Permettent d'utiliser des versions différentes par projet.
*   Configuration via un fichier `.tool-versions`.

Notes:
- **asdf**: L'outil de base, très populaire.
- **mise**: Alternative moderne (compatible `asdf`), plus rapide et plus simple. Recommandé.
- Utile pour passer d'un projet en Python 3.8 à un autre en 3.12 sans effort.
