# step-03 : Aller plus loin

## Exercice (10 minutes)

- Ouvrir `steps/step-03/main.py` : trois exercices à compléter.
- `log_decorator` : décorateur, `*args` / `**kwargs`, `functools.wraps`. `noms_adultes` : `sorted` avec une `lambda`, compréhension de liste.
- `Person` : `@dataclass`, `@property`, `__str__`, `@classmethod`.
- Remplacer les `___` et ajouter les décorateurs demandés en commentaire.
- Vérifier : `uv run python steps/step-03/verifier.py`. Objectif : `3/3 exercices réussis`. Corrigé : `steps/step-03-solution/main.py`.
- **Bonus** (exercices 4 à 6, sans trous) : générateur (`decouper`), décorateur avec argument (`repeter`), gestionnaire de contexte (`changer_dossier`).

Notes:
Les vérifications sont dans `verifier.py`, séparé pour ne pas encombrer `main.py`. En cas de ❌, la ligne de l'`assert` qui échoue s'affiche.
Dans les exercices 1 et 3, un commentaire indique où ajouter un décorateur (`@functools.wraps(func)`, `@log_decorator`, `@dataclass`, `@property`, `@classmethod`) : c'est volontaire, pour que l'étudiant écrive lui-même la ligne.
Les bonus (4 à 6) sont facultatifs, pour ceux qui ont fini : pas de trous, uniquement la consigne dans la docstring. Ils ne comptent pas dans le code de sortie du vérificateur (`bonus : 0/3`).
Si un groupe bloque : exercice 1, `wrapper` doit afficher puis renvoyer le résultat de `func(*args, **kwargs)` ; exercice 3, `from_dict` renvoie `cls(...)`.
