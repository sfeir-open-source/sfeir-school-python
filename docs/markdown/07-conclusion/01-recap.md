# Conclusion

**Ce que vous savez faire**

- **Pourquoi Python et installation** : choisir une version à jour et créer un projet avec uv.
- **Les bases** : types, collections, fonctions, exceptions, modules et bibliothèque standard.
- **Aller plus loin** : décorateurs, générateurs, classes et `@dataclass`, async, tests pytest.
- **FastAPI** : une API typée et validée avec Pydantic, persistée avec SQLModel, testée.
- **MCP** : exposer une API à un agent IA sous forme d'outils, et brancher le serveur.
