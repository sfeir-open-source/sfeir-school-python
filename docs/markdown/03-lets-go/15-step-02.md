# step-02 : Exceptions et fichiers

## Exercice

- Ouvrir `steps/step-02/main.py` : une classe et trois fonctions à compléter.
- `retirer` : exception métier avec un attribut, `try / except`.
- `charger_mots` : `pathlib`, fichier absent (`FileNotFoundError`).
- `append_if_missing` : réutiliser `charger_mots`, `with` en mode `"a"`.
- Vérifier : `uv run python steps/step-02/verifier.py`. Objectif : `3/3 exercices réussis`. Corrigé : `steps/step-02-solution/main.py`.
- **Bonus** (exercices 4 à 6, sans trous) : `parser_ligne`, `lire_personnes`, `reessayer`.

Notes:
Les vérifications sont dans `verifier.py` et utilisent un dossier temporaire : rien n'est écrit dans le dépôt. Le troisième exercice réutilise le deuxième : si `charger_mots` n'est pas fini, il échoue aussi.
Les bonus (4 à 6) sont facultatifs : pour ceux qui ont fini, pas de trous, uniquement une consigne dans la docstring. Le bonus 5 réutilise `parser_ligne` (bonus 4).
