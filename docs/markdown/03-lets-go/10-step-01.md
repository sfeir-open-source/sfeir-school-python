# step-01 : Les bases du langage

## Exercice

- Ouvrir `steps/step-01/main.py` : trois fonctions à compléter (types, f-string, ternaire, boucle, dict, set, unpacking).
- Remplacer chaque `___` par le bon code.
- Vérifier : `uv run python steps/step-01/verifier.py`. Objectif : `3/3 exercices réussis` (la ligne de l'`assert` en échec s'affiche).
- **Bonus** (exercices 4 à 6, plus difficiles) : pas de trous, juste une consigne. Durée en texte, palindrome, regroupement de mots.
- Corrigé : `steps/step-01-solution/main.py`.

Notes:
Les trous sont des lignes ou de petits blocs à écrire (une boucle, une expression conditionnelle…). Les vérifications sont dans `verifier.py`, séparé pour ne pas encombrer `main.py`. Chaque exercice est indépendant : un blocage sur le 1 n'empêche pas de faire le 2. Prévoir 10 minutes pour les trois premiers, puis corriger ensemble au projecteur avec le corrigé. Les trois bonus sont pour ceux qui ont fini : ils ne comptent pas dans le code de sortie du vérificateur (`bonus : 0/3`), et leurs corrigés sont dans le même fichier du dossier `step-01-solution`.
