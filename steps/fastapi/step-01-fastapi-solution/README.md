# Reminders for making this step

- make sure you are running python 3.12 by executing `python` in your shell
- install venv : `python -m venv .venv`
- source into your venv : `source .venv/bin/activate`
- install dependencies in the venv : `pip install -r requirements.txt`
- your main.py must be OK
- run FastAPI : `uvicorn main:app --reload`
